# Project Plan

## ITL Deliverable
Develop a working laboratory equipment and asset management application.

## AM Deliverable
Manage development using the GitHub Kanban board.

## Planned work
1. Project setup
2. Database design
3. Authentication and roles
4. Asset management
5. Asset assignment/status
6. Maintenance management
7. Complaint management
8. Dashboard and reports
9. Testing and bug fixing
10. Documentation and release

## Definition of Done
A task is complete when implementation, validation and testing are finished, changes are committed, and the related GitHub Issue is updated or closed.
